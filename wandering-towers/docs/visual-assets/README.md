### 1.4 技术栈与尺寸基线（v2 对齐现役代码）

| 项 | 值 | 来源 |
|---|---|---|
| 渲染 | React + Vite + **CSS 3D Transforms**（`transform-style: preserve-3d`），不引入 three.js | `StageViewport.tsx`、`03-UI美化与3D塔体方案.md` |
| 相机 | `perspective:1200px`、`perspective-origin:50% 40%`、`rotateX(58deg) rotateZ(rotation)`；俯角可拖 34–72° | `visual3d.ts`、`StageViewport.tsx` |
| 世界 | `worldSize 980`，缩放 0.48–3.2×；`fitWorldZoom()` 预留 9 层塔 + 城堡 + 巫师高度 | `visual3d.ts` |
| 塔 | 八边形 80 / 76px，层高 44，最多 9 层（总高 396） | 同上 |
| 地块 | 16 边形 Ø148、高 10，环半径 342；`tileSurfaceZ = 28 + 10 = 38` | `Space.tsx` |
| 棋盘 | Ø920、高 28、rim 34 | `Board.tsx` |
| 巫师 | 16 × 30，帽檐 Ø15；地面 / 塔顶最多 6 名 | `Wizard3D.tsx`、`Space.tsx` |
| 鸦堡 | 48 × 48（≈塔顶 76 的 63%） | `Castle3D.tsx` |
| 材质 | `--va-*` 变量与 `.va-*` 类（已落地） | `styles/visual-assets.css` |

> 更正：早期架构文档写 **55°** 斜俯，现役 `visual3d.ts` 为 **58°**；本素材库一律以代码为准。

**真 3D 的三条硬规则**（v1 平面板未涉及，v2 起强制）：

1. 体块 = 顶面 `clip-path` 多边形 + `translateZ(h)`，配合 N 片侧墙 `translate3d(mx,my,h/2) rotateZ(θ) rotateX(90deg)`；θ 由相邻顶点 `atan2` 得出，`backface-visibility:hidden`。
2. 顶面与侧墙**共用同一组多边形顶点**，避免边错位；Z 分层表达堆叠，不靠画出来的叠影。
3. **`filter` / `opacity<1` / `clip-path` / `overflow:hidden` 不得加在 `preserve-3d` 容器上** —— 浏览器会强制把它压成 `flat`，所有侧墙瞬间塌陷成平面。层间提亮、禁用降饱和等只能施加在叶子面元素上。

### 2.4 统一口径：识别度靠形，不靠色

保留原作的**造型符号**（可叠矮塔、蓝渡鸦盾、尖帽米宝、药水瓶、打开的书卡牌、16 格环轨、升腾悬浮）作为辨识锚点；底色沿用项目既有暗烛光舞台，避免推翻现有 CSS 基线；原作的明快色仅作为**魔法高光与点缀层**注入。所有素材统一到「暗石 + 暖烛 + 蓝符 + 金选」一套 3D 语言，不出现第二套光照或第二套几何语汇。

### 2.5 3D 转译口径：舞台层与界面层

- **舞台层**（A / B / C / E 全部，D04 骰）：进入 `preserve-3d` 世界，用真实多面体 + `translateZ` 分层，随相机旋转可见侧墙、厚度与遮挡关系。
- **界面层**（F 全部，D01 / D02 / D03 的载体）：不参与舞台 Z 排序，但同样用 `preserve-3d` 做**带厚度的实体**（4 片侧墙 + 正面），可倾斜展示侧面，不再是平面贴图。
- 两层共用 `visual-assets.css` 的材质变量与 `.va-*` 类，保证一套暗烛光视觉不分裂；E04 背景是 Canvas 2D 远景层，按设计不构成立体体块。

### 通用风格一致性约束（适用于全部条目）

1. 同一套几何语汇：八 / 十六边形平台 + 锥台，禁止出现第二套（圆球塔、哥特尖塔、机械结构）。
2. 同一套光照：58° 固定斜俯、暖烛主光 + 冷蓝补光 + 金选中辉光，禁止多光源互相矛盾。
3. 同一套材质：哑光石 / 纸 / 木 / 玻璃，禁止镜面、塑料、霓虹。
4. 核心资产禁止 emoji、纯色矩形、黑色占位块；纹章只用 C01。
5. 点缀层（酒红袍、青柠魔光、云雾蓝）不得改写台面暗烛光基调。
6. 所有素材只服务视觉，不改变点击语义、层级排序、信息可见性与 6 巫师 / 9 层塔比例基准。
7. **`preserve-3d` 容器禁止 `filter` / `opacity<1` / `clip-path` / `overflow:hidden`**（会强制 flatten、侧墙塌陷）；提亮、降饱和只施加在叶子面。
8. 顶面 `clip-path` 与侧墙必须共用同一组多边形顶点，避免边错位；`backface-visibility:hidden` 保留。
9. 素材台预览俯角默认与舞台同为 58°（可拖到 34–72°），缩放只影响观察倍率，不改变几何尺寸。

## 四、纵深 UI 的层级与字号基线（2026-11-24 追加）

> 背景：界面由「340px 单列侧栏」改为「Z 轴分层 + 四角 HUD」。本节只定义**空间与字号**，交互逻辑见
> [../architecture/08-UI纵深交互方案.md](../architecture/08-UI纵深交互方案.md)。

### 4.1 五层深度

| 层 | 内容 | 相对距离（以相机为原点） | 视觉处理 |
| --- | --- | --- | --- |
| L1 常驻 HUD | 地点 / 步数提示 / 回合 / 药水统计 / 结束回合 | 屏幕四角（DOM） | 羊皮纸薄片，不参与 Z 排序 |
| L2 资源层 | 法术牌堆 4 张 | 基准 ×1.00（最远） | 缩放 0.62、偏转 0.44rad、压暗至 0.96 |
| L3 手牌层 | 手牌 3 张 | ×0.78 | 缩放 0.90，完整亮度 |
| L4 主卡层 | 选中的 1 张 | ×0.63 | 缩放 1.10，后方双层魔法阵 |
| L5 交互层 | 移动巫师 / 移动塔 / 骰子 | 贴主卡下缘（DOM） | 羊皮纸浮层，随投影定位 |

约束：**L2→L3→L4 的距离比固定**（1.00 : 0.78 : 0.63），三档差距不足会读不出层级，超过 1.8 倍则透视失真。

### 4.2 字号基线（取代旧侧栏的 7–11px）

| 语义 | 旧值 | 新基线 | 用途 |
| --- | --- | --- | --- |
| 说明正文 | 7.5px | **12px** | 法术描述、药水脚注 |
| 卡牌主标题 | 10px | **13.5px** | 「塔 · 4」「解封巫师」 |
| 面板标题 | 11px | **13px** | 「移动魔典」「法术符文」 |
| 元信息 / 标签 | 7px | **11px** | 「消耗 1」「满 3 · 空 1」 |
| 舞台浮层大字 | 22px | **26px** | 回合轮转提示 |

下限：任何正文不得低于 11px；卡面经 CanvasTexture 渲染时，画布字号需按最终显示尺寸的 1.6 倍以上绘制，避免缩放发虚。

### 4.3 魔法阵规格

| 层 | 半径（相对卡宽） | 颜色 | 动效 |
| --- | --- | --- | --- |
| 内环 | 0.95× | 青 `#5ec3bc` | 正转 0.28 rad/s，透明度 0.24–0.34 呼吸 |
| 外环（仅主卡） | 1.20× | 金 `#e4b95f` + 青刻痕 | 反转 0.16 rad/s，透明度 0.20–0.34 |

同一时刻只允许一张卡带外环；多点同时亮金环会破坏"主卡"语义。
