07 / 风格一致性约束速查

所有条目强制遵守，供后续样式优化逐项核对。

  1. 一套几何：八 / 十六边形平台 + 锥台；禁止圆球塔、哥特尖塔、机械结构。
  2. 一套光照：55° 固定斜俯、暖烛主光 + 冷蓝补光 + 金选中辉光；侧面不得纯黑。
  3. 一套材质：哑光石 / 纸 / 木 / 玻璃；镜面、塑料、霓虹一律不用。
  4. 核心资产：禁 emoji、纯色矩形、黑色占位块；纹章只用 C01 渡鸦蓝圆徽。
  5. 点缀层：酒红袍、青柠魔光、云雾蓝不得改写台面暗烛光基调。
  6. 辨识锚点：可叠矮塔、蓝渡鸦盾、尖帽米宝、药水瓶、打开的书卡牌、升腾悬浮，缺一即失辨识度。
  7. 不越界：素材只服务视觉，不改变点击语义、层级排序、信息可见性与 6 巫师 / 9 层塔比例基准。
